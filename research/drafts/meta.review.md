## 추정 항목

- Prometheus (New Albany Data Center): 확보 전력 1,000MW 는 Meta 의 '1GW 이상 컴퓨트 용량' 표현을 그대로 쓴 값. AEP 계통분과 현장 가스(400MW) 비율, 기존 2020~2023년 건물 포함 여부는 미공개.
- Prometheus (New Albany Data Center): 2026 2분기 통전 200MW·시운전 시작은 추정: Williams 가 Socrates 1단계 200MW 를 '고객에게 공급' 했다고 밝혔으나 Meta 는 Prometheus 가동을 공식 발표하지 않음. 데이터센터 목록 사이트(Tier 3)는 2026년 신축 건물을 '가동 중' 으로 표시.
- Prometheus (New Albany Data Center): announced 를 2025-07(Prometheus 공개)로 둠: 캠퍼스 자체는 2017 착공·2020 가동이지만 AI 클러스터 전환이 공식화된 시점부터 지도에 표시. 건물별 MW 가 없어 lite.
- Prometheus (New Albany Data Center): 좌표는 뉴올버니 시 중심. 실제 캠퍼스는 Beech Rd·SR-161 인근 Licking County 쪽(보도) — 공식 주소 미확인.
- Hyperion (Richland Parish Data Center): 1단계 확보 전력 2,000MW: Entergy 승인 발표에 MW 가 없어 언론의 '2GW 데이터센터'(DCD) 와 승인 발전량 2,262MW 중 낮은 값을 사용. 2024-12 단계는 발표 당시 목표로 표시.
- Hyperion (Richland Parish Data Center): 2026-07 부터 확보 전력 5,000MW 는 Meta 의 5GW 목표값. 2단계 발전설비(가스복합 7기)는 LPSC 승인 전(2026-12-16 심의 예정)이라 승인되면 reported 로 바꿀 것.
- Hyperion (Richland Parish Data Center): 1단계 진행률 0.3: 2024-12 착공 후 22개월, 2029 리스 개시(시운전 목표)까지 약 60개월 중 경과 비율로 근사. 공개 진척률 없음.
- Hyperion (Richland Parish Data Center): 2단계 완공 2032 은 추정(백과사전·언론의 '전체 완공 2032년 무렵'). Meta 공식 표현은 '수년에 걸쳐 5GW'.
- El Paso Data Center: 2025-10 확보 전력 440MW 는 추정: 텍사스 PUC 서류 보도(Argus)에 따르면 Meta 자회사 Wurldwide LLC 가 처음 220MW 를 요청, 2027년 440MW 이상, 2029년 1GW 가능. 회사 공식 수치 아님.
- El Paso Data Center: 1단계 440MW / 2단계 560MW 분할과 2단계 2029 가동은 위 PUC 보도의 부하 증가 일정으로 나눈 추정. Meta 는 '2028년부터 순차 가동' 만 공개.
